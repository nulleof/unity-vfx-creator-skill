# VFX Creator roadmap

## Mobile UI VFX

The first milestone is to author editable screen-space effects, preview them in a live game UI, and verify that they preserve input, readability, and frame pacing. Start with uGUI and URP in Unity `6000.6.8f1`.

### Design guidelines

- **Make feedback immediate and proportional.** Anchor the effect to the control or value that changed. Use brief, local feedback for frequent actions like button presses or cooldown completion. Reserve larger effects for rare moments like a reward reveal. Let players interact while the effect plays and let them skip longer reveals. [Apple HIG — Motion](https://developer.apple.com/design/human-interface-guidelines/motion)
- **Keep the result readable.** Make important outcomes visible through a persistent UI state, a label, or an icon. For example, a reward reveal leaves the amount visible after the particles clear, and a ready ability has a visible state even with motion and sound turned off. Keep essential cues and controls inside the safe area and readable at peak effect intensity. [Apple HIG — Designing for games](https://developer.apple.com/design/human-interface-guidelines/designing-for-games), [Xbox Accessibility Guideline 103 — Additional channels for cues](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103)
- **Provide a reduced-motion variant.** Replace large moves, zooms, and bounces with a static state change or brief fade. Suppress decorative loops and screen shake in this mode. Honor iOS Reduce Motion and expose an in-game setting on both platforms so players can choose how much motion they see. [Apple HIG — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility), [Xbox Accessibility Guideline 117 — Motion settings](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/117)
- **Review the final composite for flashing.** Avoid strobing, saturated red flashes, and large high-contrast flashing patterns. Evaluate captures in both motion modes at the fastest supported retrigger rate and with effects overlapping. [Xbox Accessibility Guideline 118 — Photosensitivity](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/118)
- **Budget for peak overlap.** Keep translucent layers compact and limit simultaneous emitters. Disable raycast targets on decorative graphics. Separate frequently changing uGUI effects from static UI where profiling shows a rebuild cost. Compare CPU and GPU frame times with effects enabled and disabled on target phones. [Unity — UI optimization tips](https://unity.com/how-to/unity-ui-optimization-tips), [Unity 6000.6 — Collecting performance data](https://docs.unity.com/en-us/engine/6000.6/manual/analysis/profiler/profiling-applications), [Android Developers — Frame pacing](https://developer.android.com/games/sdk/frame-pacing)

### Planned work

- [x] **Define the UI brief and handoff.** Record the trigger, target control, anchor, footprint relative to the control, render order and clipping, the retrigger policy, and the reduced-motion treatment. The [UI effects workflow](vfx-creator/references/ui-effects.md) covers Screen Space – Overlay.
- [x] **Build three pilot recipes.** Cover a button confirmation, a cooldown-ready cue, and a reward reveal. Export editable prefabs and preview each inside a representative menu or HUD. The [pilot check](tests/Test-UiEffects.ps1) verifies pointer input through active effects, overlap, sorting, clipping, skipping, and reopening in Play Mode.
- [ ] **Add a mobile review fixture.** Capture each pilot in standard and reduced-motion modes on light and dark backgrounds at compact and tall aspect ratios. Check safe-area placement, readability at peak intensity, and flashing in the composited captures. Profile the busiest expected interaction on a low-tier Android phone and a supported iPhone. Record the hardware, FPS target, CPU/GPU frame times, and Canvas rebuild cost with effects off and on. Set the allowed incremental cost for the target devices before sign-off.
