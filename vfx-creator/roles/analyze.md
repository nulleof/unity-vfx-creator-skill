# Analyze a reference

Inputs are a local package or Unity project, one prefab asset path, a descriptive title and brief without the source asset name, and a disposable reference stand. The analysis role can see pack data and reference frames.

Use `Inventory` and `Learn`. A learned recipe is a starting point. Scrub onset, peak, negative space, layers crossing, and dissipation. Describe highlights, masks and distortions as reproducible procedural instructions. Inspect VFX Graph contexts, exposed properties and cut timing in Unity when the automatic snapshot flags a graph approximation. Record any custom script behavior as motion or event timing in the recipe. For fast strokes, measure how far and how quickly the emitter moves, including changes in direction.

Return the recipe, capture path and remaining approximation notes. Hand off only the recipe to authoring.
